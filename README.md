# 💫 100 Días de Novios — Experiencia Cinematográfica

Una experiencia web interactiva romántica hecha con amor, pensada para celebrar 100 días juntos.

---

## 📁 Archivos necesarios

```
📁 Mi carpeta
   🗒️ index.html   ← la experiencia completa
   🎵 musica.mp3   ← tu canción (la agregas tú)
```

> ⚠️ Los dos archivos deben estar **en la misma carpeta** para que la música funcione.

---

## 🎵 Cómo agregar la música

1. Entra a **ytmp3.cc** desde tu navegador
2. Busca tu canción en YouTube y copia el link
3. Pégalo en ytmp3.cc y descarga el archivo
4. Renombra el archivo descargado exactamente así: `musica.mp3`
5. Ponlo en la misma carpeta que el `index.html`

---

## 🌐 Cómo publicarlo y enviar el link

La forma más fácil y **100% gratis** es con **Netlify Drop**:

1. Entra a 👉 **app.netlify.com/drop**
2. Mete los dos archivos (`index.html` y `musica.mp3`) dentro de una carpeta
3. Arrastra esa carpeta completa al recuadro de la página
4. Espera unos segundos — te aparece un link automático
5. Copia el link y mándalo por WhatsApp ✨

> El link se ve así: `https://nombre-aleatorio.netlify.app`
> Se puede abrir desde celular o computadora sin descargar nada.

---

## 💻 Cómo abrirlo sin internet (modo offline)

Solo haz **doble clic** en el archivo `index.html` y se abre directo en tu navegador. No necesita internet para funcionar, solo para cargar las tipografías la primera vez.

## 🛠️ Detalles técnicos

- Un solo archivo HTML — sin dependencias externas de pago
- Funciona **offline y online**
- Compatible con **celular y PC**
- Audio generado con **Web Audio API** (latidos, maullido)
- Tipografías: **Cormorant Garamond** + **Raleway** (Google Fonts)
- Animaciones con **CSS puro + Canvas API**
- No usa frameworks ni librerías externas
